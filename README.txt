CẬP NHẬT VOCAB GARDEN — THE FORUM CENTER

1. Sao lưu dữ liệu hiện tại trong website: Thêm từ > Xuất dữ liệu JSON.
2. Mở github.com/ydungkuan-x/thanhtam > Code > Add file > Upload files (hoặc sửa index.html).
3. Thay index.html cũ bằng index.html của gói này, Commit changes. Đợi GitHub Pages cập nhật và tải lại trang.
4. LocalStorage trên cùng tên miền vẫn giữ tiến độ. Nếu trình duyệt đổi/xoá dữ liệu, Nhập file JSON đã sao lưu.
5. Bộ từ mới từ tài liệu nằm trong 10 nhóm Forum. Các bản ghi trùng sẵn có không được nhân đôi.
6. Nếu chưa muốn thay file trên GitHub, bạn có thể nhập forum_import.json từ mục Thêm từ -> Nhập file JSON/CSV trên website hiện tại.

Ghi chú: IPA của mẫu cấu trúc có chỗ trống (+ V, noun, clause) để trống có chủ ý; nút loa vẫn đọc mẫu tiếng Anh nếu trình duyệt hỗ trợ. Các IPA ghép khác là tham khảo.
